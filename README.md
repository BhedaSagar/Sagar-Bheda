## 🤖 AI & RAG

I'm currently exploring the intersection of **Backend Engineering and Generative AI**.

One of my projects is a knowledge-base RAG system that combines:

* 📚 Document-based knowledge retrieval
* 🔎 Semantic search
* 🧩 Text chunking and embeddings
* 🗃️ PostgreSQL + pgvector
* 🍃 MongoDB for document management
* 🧠 LLM-powered responses
* ⚡ Node.js / Sails.js backend
* 🤖 LLM integration using Groq

The goal is to build AI applications that can retrieve relevant information from a knowledge base and generate useful, context-aware responses.
